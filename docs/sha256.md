# sha256

SHA-256 hashing and constant-time string comparison.

```ts
import { createSha256Hash, timingSafeStringEqual } from '@linagora/twake-crypto-utils';
```

## `createSha256Hash(input)`

```ts
const digest = await createSha256Hash('payload');
// → 44-character standard base64 string (with '=' padding)
```

Output is **standard base64** (with `+`/`/` and `=`), not base64url and not hex. Use `hexEncode` (see [encoding](./encoding.md)) if you need hex.

| Param | Type | Notes |
|---|---|---|
| `input` | `string` | UTF-8 encoded. |

## `timingSafeStringEqual(provided, expected)`

Constant-time string comparison. Synchronous, pure JS - no Node `timingSafeEqual`, no `Buffer`.

```ts
const ok = timingSafeStringEqual(providedDigest, expectedDigest);
```

- Returns `false` if either argument is empty.
- When lengths differ, walks the longer string anyway so runtime cost depends on the *expected* length and not on where the strings first diverged.
- Operates on UTF-16 code units. Inputs with astral-plane characters (surrogate pairs) will compare correctly, but you almost certainly want to compare hex or base64 digests here, where every character is a single code unit.

## Examples

```ts
import { createSha256Hash } from '@linagora/twake-crypto-utils';

const integrity = await createSha256Hash(JSON.stringify(payload));
// store alongside payload; check on read to detect corruption
```

```ts
import { timingSafeStringEqual } from '@linagora/twake-crypto-utils';

if (!timingSafeStringEqual(req.headers['x-api-key'], process.env.API_KEY!)) {
  return res.status(401).end();
}
```
